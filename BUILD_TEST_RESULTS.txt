Security and release caveats
- WAV writer and session saver use same-directory temporary files and atomic create/replace on POSIX; no-overwrite is enforced at final creation. Symlink targets are rejected. Session load is bounded to 4 MiB and refuses symlink input.
- No network-isolated namespace/packet-capture/DNS monitoring run was completed for this exact package. CMake contains no FetchContent or dependency download logic; PortAudio and X11 are system libraries only.
- PortAudio output was not tested against a physical audio device. GUI uses the OS default output device and has no device chooser/hotplug recovery.
- MIDI support is a bounded event queue, not OS MIDI I/O. Plugin support is an in-process DSP interface, not VST3/CLAP/AU binary hosting. Recording and monitoring are not implemented.
- Windows/macOS/ARM native builds were not run. A GitHub Actions matrix for Ubuntu/Windows/macOS was added but remote CI has not been executed.
- Full ASan/UBSan detector-calibration, TSan, parser fuzzing, independent third-party audit and security certification are not claimed.
- Optional clipboard-MCP and server-protection tools remain excluded from the HUSH build; they were not fully reviewed or activated.
